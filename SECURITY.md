# Security Policy

## Project Status

Sentinel Log Analyser is currently in public beta.
It is intended for defensive security log analysis and
is not guaranteed to be suitable for production use.

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.4.x   | Yes       |
| < 0.4   | No        |

Security fixes are evaluated against the latest beta release.

## Reporting a Vulnerability

Please use GitHub's private vulnerability reporting feature
for this repository to report suspected security vulnerabilities.

Do not disclose vulnerability details publicly before the
maintainer has had an opportunity to investigate.

Please include, where possible:

- The affected version
- A description of the vulnerability
- Steps to reproduce the issue
- The potential security impact
- Relevant logs or evidence with sensitive information removed

## Response and Disclosure

Reports will be reviewed by the maintainer as time permits.
Please allow time for investigation before publicly disclosing
an unpatched vulnerability.

This project is maintained on a best-effort basis. A response
or fix within a specific timeframe is not guaranteed.
